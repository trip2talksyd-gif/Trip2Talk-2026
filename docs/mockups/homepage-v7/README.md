# Homepage mockup v7 — approved by Saen (2026-10-23)

Open `index.html` locally to view. Photos in `img/` are stills taken from the site's own trip videos (`public/hero`, `public/trip-videos`). No stock images.

## Direction
- **Mobile-first.** Sticky bottom bar on phones: "ทักแชท" (m.me/TriptoTalk) + "ดูทริปที่เปิดรับ". Buttons 48–52px tall, body text 16–17px.
- **Sells the experience** of travelling with a real photographer: small group (max 6), real light (เก็บแสง), premium photos you keep. Key line: "ทริปที่เติมเต็ม ทั้งใจและกล้อง".
- **Colours = live site tokens:** cream `#f7f5f0` / white cards, ink `#1b2a2c`, deep green `#16262b` / `#122f2a` for dark sections, orange `#e6935a` buttons (text in deep green), deep orange `#c46e37` for highlighted words on cream.
- **Fonts:** Thai headings **Kanit Light (300)** with one highlighted phrase per headline in Kanit 500 + orange. English display **Bricolage Grotesque** (upright). Body **Sarabun**.

1. Header: logo, YouTube + Facebook icon buttons, "จองทริป" (desktop).
